# Фэнтезийный Telegram Бот-Игра

## Описание
Это Telegram-бот для фэнтезийной онлайн-игры в mini app формате. Игрок начинает как простой путешественник с нулевым уровнем и может перемещаться по огромной карте, содержащей королевства, деревни, гильдии, магазины, таверны и другие локации.

## Особенности
- Система персонажей с уровнями, здоровьем, маной, опытом и золотом
- Карта с различными типами локаций
- Возможность перемещения по карте
- Система инвентаря
- Интерактивные локации (таверны, магазины, гильдии и т.д.)

## Команды
- `/start` - Начать игру
- `/map` - Посмотреть карту мира
- `/status` - Показать статус персонажа
- `/move [направление]` - Перемещение (north/south/east/west или координаты)
- `/explore` - Исследовать текущую локацию
- `/help` - Справка по командам

## Установка и запуск

1. Установите зависимости:
```bash
pip install aiogram
```

2. Получите токен у [@BotFather](https://t.me/BotFather) в Telegram

3. Замените `YOUR_TELEGRAM_BOT_TOKEN` в файле `run_bot.py` на ваш токен

4. Запустите бота:
```bash
python run_bot.py
```

## Структура проекта
- `telegram_bot.py` - Основной код бота с игровой логикой
- `run_bot.py` - Скрипт для запуска бота
- `README.md` - Этот файл документации

## Игровой процесс
Игрок начинает в начальной деревне и может:
- Исследовать карту
- Посещать различные локации
- Взаимодействовать с NPC
- Развивать персонажа
- Собирать ресурсы и опыт
